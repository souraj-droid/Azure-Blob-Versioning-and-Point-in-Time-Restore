Blob Management (normal user)

Upload, view blobs, view versions. Version Restore: restore a selected previous blob version.

Point-in-Time Restore (administrator only)

Restore supported block-blob data to an earlier UTC point in time. Administrator permission required.

PIT Restore requires Storage Account Contributor. Normal application users cannot execute PIT restore; they should use Version Restore above. This form validates the timestamp and prepares the administrator command — it does not perform the restore itself.

Demo note: The 30-day PIT window is configured from the date PIT restore was enabled. The full 30-day historical range becomes available as time passes. For a valid demo, create changes after PIT was enabled (e.g. 20:00 original, 20:05/20:10/20:15 updates) and restore to 20:05.

Validation only — an administrator runs the Azure Restore Blob Ranges operation. Only one restore per account at a time.

Demo: accidental overwrite (report.txt)

  1. Upload report.txt with "This is the original project report."
  2. Overwrite it with "This report contains incorrect data."
  3. Open Versions, then Restore the previous version.
  4. Download current to confirm recovery.
